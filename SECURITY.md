# Security Policy

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Please report vulnerabilities by emailing the maintainers at [SECURITY_EMAIL_TBD].

Include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested mitigations

You will receive a response within 72 hours acknowledging receipt.

## Scope

- `contracts/beatsplit` — the Soroban smart contract (in scope)
- `app/` — the Next.js web app (in scope)
- Third-party dependencies — please report upstream; we will patch promptly

## Disclosure Policy

We follow responsible disclosure. We aim to patch confirmed vulnerabilities within
30 days and will coordinate public disclosure with the reporter.

## Known Limitations

⚠️ **This software is unaudited. Do not use it with significant real funds until a
professional third-party audit is complete and results are published.**
